llm-gateway

One place for the provider keys. Everything else points here.

Unlock with the admin token to manage keys and clients.

Add keys

Paste one or more keys for a single provider below — newlines, commas or spaces between them. Each call takes the key at the front of the queue and sends it to the back, so several keys — from one provider or several — multiply the free tier's daily cap instead of spending one down.

Default models

What each provider is asked for when nothing more specific applies. Providers rename and retire models — set one here to fix it immediately, no deploy. Leave blank to fall back to the built-in default shown as the field's placeholder.

Rotation queue

Test asks the provider about that one key alone, outside the rotation — a typo is worth finding now rather than a week later, when every caller has quietly been served by the others.

Clients

Each app gets its own token, so usage is attributable and one app can be cut off without touching the others. A token is shown once and stored only as a hash.

Usage

Client token

This page talks to the gateway exactly the way any other app does — over POST /v1/chat/completions with a client token, not the admin one. Issue one in the Console tab; it is shown once, at issue.

The default pool routes every call to a different model, so each reply says which one actually answered and which key served it.
